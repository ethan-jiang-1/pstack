# 我该用 `/poteto-mode`，还是直接调单个 skill？

> [FAQ 首页](../README.md) · [直接回答](./answer.md)

## 问题要解决什么

pstack 装好之后，面对一个具体任务，第一反应往往是"要不要进 mode"。进 mode 意味着匹配 playbook、复制步骤、按角色派 subagent，成本更高；直接调 `how`、`unslop` 或 `tdd` 更轻，但需要自己知道用哪个、顺序是什么。

这个问题只讨论入口选择，不展开每个 playbook 的内容，也不讨论安装多少 skill。

## 不在本问题范围内

- 具体该选哪个 playbook：见 [playbook 索引](../../_digest/playbooks/README.md)。
- 只装了一部分 skill 时能不能跑 mode：见 [05](../05_which-skills-to-install/answer.md)。
- 没有子代理时怎样降级：见 [02](../02_single-model-no-subagents/answer.md)。
