# 能只装几个 skill 吗？要装哪些？

> [FAQ 首页](../README.md) · [直接回答](./answer.md)

## 问题要解决什么

pstack 的 README 既给了"这些 skill 互不调用，可以单装"的列表，又给了"`poteto-mode` 需要大多数 skill"的依赖表。读者容易在两种做法之间摇摆：全装太重，只装几个又怕断链。

这个问题讨论安装范围、最小集合与部分安装的断点。不讨论具体安装命令的每条参数。

## 不在本问题范围内

- 装好之后用 mode 还是单 skill：见 [01](../01_mode-or-single-skill/answer.md)。
- 模型设置文件的配置：见 [04](../04_model-panel-and-budget/answer.md)。
