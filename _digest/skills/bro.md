# `bro`

> 源码：[`skills/bro/SKILL.md`](../../skills/bro/SKILL.md)
> 调用：**U**（user-invoked，只有人能触发）
> 索引：[技能索引](./README.md) · [系统总览](../system/README.md)

## 一句话

让 agent 把自己上一段回复用平实的人话再说一遍：去掉术语，说得更简单、更短。

## 它解决什么

强模型的回复容易堆术语、嵌套从句和抽象名词。每个词用户都认识，但抓不住整句在说什么。再追问一句"什么意思"通常只会得到同样密度的回答，因为模型会以为缺的是信息，而不是表达。

`bro` 换了一个要求：不补充新内容，把刚才那段话**重说**一遍。名字本身也是口语的，与它要的语域一致。

## 核心机制

### 1. 对象是 agent 自己的上一段话

正文写的是"Restate your last message"，不是用户的消息，也不是整段对话。description 里写的是"the last message"，没有指明是谁的；正文用"your"把它定死（见 **值得注意**）。

### 2. 四条要求，一个方向

停止使用术语；把话说连贯；更简单、更简洁；像一个人对另一个人说话。四条都指向**语域**，不是内容量。

### 3. 是重述，不是重新回答

"Restate" 的语义是同一内容换一种表达。允许变短，但没有授权改结论、加新信息或换立场。这一点是从词义推出的，源码没有另写一条约束。

### 4. 单轮、无状态

它只处理最近一条消息，不引用更早的上下文。因此前一条回复如果答错了，`bro` 会把错误也说得更顺；如果关键信息在更早的消息里，它不会补回来。

### 5. 由人触发

`disable-model-invocation: true`，模型不会自己调用。mode 的 **Non-negotiables** 没有它的条目；它出现在 `poteto-help` 的 **Pick a skill** 表和 [`recipes.md`](../../skills/poteto-help/references/recipes.md) 的 **Away and back** 一节末尾。

## 设计意图

- **可读性是独立于正确性的维度。** 一段正确的回复可以完全无法读，所以值得单独要一次。
- **重述而不是解释。** 解释会引入新信息和新错误；重述只在原内容上换表达。
- **语域本身就是问题。** 用户说"bro"，要的不是更短的报告，是换一种说话方式。
- **不规定格式。** 要打破的正是格式化表达，再给模板会重复同一种失败。

## 依赖关系

- **上游**：人输入 `/bro`；`poteto-help` 的表格把它写成"Hear the last reply again in plain words"。
- **下游**：没有。它是一次性重述，不接流程。
- **共享**：与 mode 的 **Writing the reply** 和 `unslop` 都在管表达质量，但时机相反：那两者在写的时候避免坏表达，`bro` 是写完之后的补救。
- **对照**：`in-your-own-words` 复述用户的目标，`bro` 复述 agent 的回复；`ketchup` 汇总一段对话的变化，`bro` 只重说一条消息。

## 使用边界

- **不能修复错误结论。** 它只改表达；答错的内容会被说得更顺，反而更难发现。
- **只覆盖最后一条消息。** 长回复被压缩后，可能正好丢掉用户没看懂的那部分。
- **术语不总是冗余。** 源码要求停止使用术语，但没有给必要专有名词（API 名、类型名、错误码）留例外；去掉之后用户可能失去回去查文档的抓手。
- **对已经平实的回复是纯开销。** 它不会判断上一段是否已经够清楚。
- **没有确认环节。** 重述完是否解决了困惑，取决于用户再读一遍。

## 值得注意

- **description 与正文的对象不一致。** description 说"the last message"，正文说"your last message"。按正文理解才成立，但只读 description 的人可能以为它重述用户的话。
- **"更简洁"与"别丢内容"没有边界。** 源码同时要求更简单和更简洁，没有说哪些细节必须保留；压缩比例完全由模型判断。
- **只能由人触发。** agent 不会在长回复后主动提议用 `bro`，所以发现表达失败的仍是用户。
- **补救不如预防。** 如果同一段对话里反复需要 `/bro`，问题在 mode 的 **Writing the reply** 或 `unslop`，不在这一条命令。

## 关键洞察

1. **可读性要单独要求。** 正确性和可读性不是同一个轴，一次只优化一个。
2. **重述是最小成本的第二次机会。** 不重做工作，只重做表达。
3. **口语化不是简化内容。** 它换的是语域，不是事实。
4. **事后补救暴露的是写作阶段的缺口。** 需要补救的频率，是文体规则是否生效的信号。
